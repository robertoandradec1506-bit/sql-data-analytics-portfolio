# Northwind SQL Analysis

A SQL portfolio project focused on sales analysis, customer behavior, product performance, supplier relationships, and revenue trends using the Northwind relational database.

## Project Overview

This project explores the Northwind database to answer business questions related to sales operations and commercial performance.

Using SQL, I analyzed relationships between customers, orders, products, suppliers, employees, and invoices to extract meaningful information from relational data.

The project demonstrates my ability to query structured datasets, combine information across multiple tables, aggregate transactional records, and answer business questions using SQL.

## Objectives

* Analyze sales performance across products, employees, and product categories.
* Identify customers who have never placed an order.
* Evaluate supplier performance based on products associated with sales transactions.
* Explore revenue trends over time.
* Apply SQL techniques to solve practical business questions.

## Tools & Technologies

* **SQL:** Data querying, filtering, joins, aggregation, and business analysis.
* **SQLite:** Database engine used for querying the Northwind dataset.
* **GitHub:** Version control and project documentation.

## Database Overview

Northwind is a relational database representing a business that manages customers, orders, products, suppliers, employees, and shipping operations.

The project uses interconnected tables to analyze commercial activity from different perspectives.

| Table           | Purpose                                                 |
| --------------- | ------------------------------------------------------- |
| `Customers`     | Customer information and contact details                |
| `Orders`        | Order records and shipping information                  |
| `Order Details` | Products, quantities, and prices associated with orders |
| `Products`      | Product information and inventory                       |
| `Categories`    | Product category information                            |
| `Suppliers`     | Supplier information                                    |
| `Employees`     | Employee information and reporting relationships        |
| `Shippers`      | Shipping company information                            |
| `Invoices`      | Invoice-related sales information                       |

These tables provide the foundation for analyzing customer activity, product sales, supplier relationships, employee performance, and revenue.
