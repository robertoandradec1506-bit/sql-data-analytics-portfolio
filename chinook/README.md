# Chinook Database — SQL Business Analysis

## Project Overview

This project explores the Chinook database using SQL to answer business questions related to music sales, customer spending, invoice activity, playlists, and sales performance.

The analysis focuses on transforming relational data into meaningful business insights using SQL queries, aggregations, joins, subqueries, Common Table Expressions (CTEs), and date-based analysis.

The project includes **9 selected SQL queries** designed to demonstrate practical SQL skills through business-oriented questions.

## Project Objectives

* Analyze invoice distribution across countries.
* Compare average track prices across music genres.
* Evaluate revenue associated with Sales Support Agents.
* Examine the number of tracks included in playlists.
* Compare invoice activity and revenue across selected years.
* Identify invoices with above-average values.
* Determine which customers generate the highest total spending.
* Calculate the average number of tracks purchased per customer.
* Analyze monthly revenue trends throughout 2009.

## Tools & Technologies

* **SQL**
* **SQLite**
* **Chinook relational database**
