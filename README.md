# SQL Data Analytics Portfolio

This repository showcases my practical SQL skills through
relational database exercises and analytical projects.

My goal is to use SQL to explore datasets, answer business
questions, and extract meaningful insights.

- SQLite

- JOINs and relational data analysis
- Aggregations and GROUP BY

- Date-based analysis
- Window functions
